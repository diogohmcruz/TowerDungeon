# Only Old Hands are individuals

Abilities, experience and arête belong to named Old Hands (a survivor of a near-death Expedition or of three Expeditions), at most twelve at once, each holding up to three abilities. Every other unit stays interchangeable: a type, an origin and its rolled traits, with no identity of its own.

We want unit customisation, which the book builds from named, advancing characters, but making every unit an individual needs named selection for Parties and Waves, a stable unit id, per-unit rules and a scene that shows the differences at 11-12 px figures. `docs/brainstorm/roguelite-layer.md` section 3.6 already rejected a second stat-inflation system for this reason. We chose a small cap of veterans so the plumbing is built once and the player still has units to care about; we rejected per-unit abilities for everyone as too large and unreadable.

## Consequences

- Stable unit ids and named selection become prerequisites for abilities (they were already prerequisites for Lessons).
- An Old Hand in the reserves can still die to Village Starvation, so the Ledger line names the lost abilities.
- Raising the cap later is a number, but making all units individuals is a different design.
